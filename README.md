# E-Commerce Marketplace

A Laravel 12 marketplace for digital products with dedicated experiences for buyers, creators, affiliates, content reviewers, and administrators.

## Highlights

- Product discovery, search, categories, creator storefronts, wishlists, and reviews
- Cart and direct-purchase checkout flows with coupons
- Buyer order history, licensed downloads, and digital library
- Creator product management and moderation responses
- Affiliate referrals, commissions, and payout requests
- Role- and permission-based administration
- Bakong KHQR and optional ABA PayWay card payments
- Google OAuth authentication

## Project Location

The Laravel application lives in [`e-commerce/`](e-commerce/). See the [application README](e-commerce/README.md) for requirements, installation, configuration, payment integration, testing, and deployment notes.

## Quick Start

```bash
git clone https://github.com/xyrvt4mwzk-ops/ecommerce-project.git
cd ecommerce-project/e-commerce
composer setup
composer dev
```

The application is available at `http://127.0.0.1:8000` by default.
